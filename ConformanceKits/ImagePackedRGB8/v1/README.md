# ImagePackedRGB8 conformance v1

This kit owns the finite public contract for the opt-in, one-shot, hard-bounded baseline JFIF RGB8 producer. It intentionally does not test the default ImageIO backend, general JPEG support, progressive lifecycle, device RSS, host persistence, or release qualification.

The v1 profile is the finite union of four frozen baseline JFIF controls: one 19x11 grayscale source plus 23x13 4:4:4, 4:2:2 and 4:2:0 color sources. Every source byte stream is SHA-256 bound, and every expected tight RGB8 payload is frozen independently from libjpeg-turbo `djpeg` 3.2.0 rather than generated by the backend under test. Exact codec-owned operation peaks are 836 B for grayscale, 1,601 B for 4:4:4, 3,073 B for 4:2:2 and 3,777 B for 4:2:0; transfer sizes are 627 B for grayscale and 897 B for the three color controls. Encoded JPEG bytes remain caller-owned.

The six obligations run across all four modes and cover deterministic probe facts, exact phase resource authority, caller-owned encoded-source coexistence, exact independent RGB8 output, DecodeLimits, the exact public request slice, and hard operation-budget failure. The fixture matrix therefore validates the complete public baseline JFIF union without multiplying the number of process-level gates.

This fixture set does not prove general JPEG support. In particular it does not qualify non-JFIF grayscale, progressive JPEG, 4:4:0 sampling, ICC/Exif/auxiliary or unknown APP semantics, resizing, HDR, or default-backend adoption. Reports set `releaseQualified=false` by contract.
